# 💡 OneShot - Niko (Glass)

A lightweight, frosted-glass BetterDiscord theme inspired by the warm, atmospheric colors and aesthetic of **OneShot**. Features full transparency, custom multi-layered glass blurs, and smooth dynamic animations.

---

##  Features

- **Glassmorphism UI:** Multi-layered transparency with distinct backdrop blur values for panels, toolbars, member lists, and chat containers.
- **OneShot Palette:** Custom color variables featuring deep purples, warm creams, rich magentas, blush pinks, and bright gold accents.
- **Animated Channel Hovers:** Smooth, sliding gradient hover animations on channel lists (`--os-blush` to `--os-magenta-bright`).
- **Frosted Embeds & Input:** Custom styled message area and embed cards with gold border accents.

---

##  Installation

### Prerequisites
Make sure you have a Discord client mod installed that supports custom CSS themes (such as [BetterDiscord](https://betterdiscord.app/), [Vencord](https://vencord.dev/), or [Replugged](https://replugged.dev/)).

### BetterDiscord
1. Download or copy any version of `OneShot-Niko.theme.css`.
2. Open Discord and go to **User Settings** -> **Themes** (under *BetterDiscord*).
3. Click **Open Theme Folder**.
4. Move `OneShot-Niko.theme.css` into the folder.
5. Toggle the theme **ON** in Discord.
